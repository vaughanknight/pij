Two compounding meta-failures: safety mechanisms that **silently stay off** (my mass watchdog-exemption outlived its incident and blinded hyena's detector), and **shared-instrument corroboration** (4 seats "confirmed" the pause no-op because all 4 read the same lying display — INS-002).

## 2b. Second cross-cutting pattern — worktree-cwd assumptions (mastodon)
Worktree-dwelling is now the **normal** mode — the dogfood and every stream run in worktrees — but multiple seams still assume `cwd == repo-root`. Three instances this week alone: (1) telemetry transcript-mangling on a worktree cwd; (2) folder-filtered baton resolver defeated by `cwd ≠ folder` (→ INS-004, fixed `faf06c5`); (3) an adopt-time `boundModel` item. **Systematic fix over whack-a-mole**: audit for `cwd == repo-root` assumptions; resolution/telemetry/identity must key on **recorded identity** (pane / pid / registered folder), never the live cwd. Folds into Stream 3 (identity is the sharpest instance) as a "worktree-native correctness" audit — but it spans telemetry too, so it's a lens to apply across the round, not one ticket.
