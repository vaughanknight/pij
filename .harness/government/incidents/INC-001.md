# INC-001 — o-prime `git add -A` swept a live stream's fenced files (repaired)
**Opened**: 2026-07-11T09:30:00Z · **Closed**: 2026-07-11T09:33:00Z · **Causer**: pij-3vetx8 (o-prime — self-report)

## What happened
While committing the live-resource verification doctrine, the o-prime ran its habitual `git add -A`. s036 (pij-1khprxk) was mid-explore in the same tree; the sweep staged its in-flight fenced artifacts (`research-dossier.md`, and its just-written plan doc + flow files), and `research-dossier.md` shipped inside the o-prime's commit. Detected immediately from the commit output (the causer reading its own stat — INC-004's detection pattern exactly).

## Containment + repair (verified)
`git reset --soft HEAD^` → unstage the stream's entire fence → recommit **pathspec-limited** to the two payload files. Verified: `git show --stat HEAD` = 2 files, both payload; `git status` shows s036's artifacts back to their pre-sweep working-tree state (modified/untracked, unstaged); byte content never touched.

## Root cause (a gap, not a blame line)
The standing rule existed (baton book, day one: pathspec-mandatory commits) but had no mechanical backstop — the causer's muscle-memory `add -A` was the paved path. Second occurrence of this class today (T001's sweep during dlg-0001 was the first); a rule violated twice by its own author in one day is a missing check, not a character flaw.

## Standing rule (re-affirmed + sharpened, broadcast to s036)
O-prime commits in this repo are **pathspec-mandatory with the stream fences explicitly excluded** — the commit command names its paths, never `-A`, while any stream is live.

## Encode candidate (provenance: this incident + T001 sweep + run-01 INC-004)
Mechanical backstop: a pre-commit guard (or `just oprime-commit <paths>` recipe) that refuses staged paths inside any spine-fenced stream dir unless the committer IS that stream. Third strike of the class today across two repos — earns tooling, not another prose rule. → feeds s036's baton/orchestration design (git-index semantics) or a small standalone fix.
