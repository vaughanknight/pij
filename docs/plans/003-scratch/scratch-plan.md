## Summary

Build pij's first **kept** extension — `scratch`, a session-scoped notepad
— using the v0.1.0 harness path. Three deliverables ride together: a
working `/scratch` extension end-to-end (10 functional ACs); empirical
D-005 verification (does `customType` survive `/compact`?); the first
real-extension wall-clock data point logged in `docs/velocity.md`. AC-15
from the harness spec (compounding ratio) is **decoupled** from this PR
per clarify Q3 — scratch produces the data point, ratio judgment defers
to extension #3.

Design is locked in [workshop 003](../001-pi-extensions/workshops/003-scratch-extension.md)
(942 lines, paste-ready). This plan is the adaptation path: scaffold via
`npm run new -- scratch`, then replace template content with workshop
003's design, file-by-file.
