## Jordan's observation (2026-09-07, two machines, latest code)

Since PR #374 the extension injects via omp's custom-message API (`.pi/extensions/pij/adapters/pi-runtime.ts inject()`: `pi.sendMessage({customType:'pij', content, display:true}, {triggerTurn:true, deliverAs:'steer'})`) instead of `pi.sendUserMessage(text,{deliverAs:'steer'})`, because a user-role message makes omp clear the editor (the clobber, installed dist/cli.js:19099 per gazelle).
