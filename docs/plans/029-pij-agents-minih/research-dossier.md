## Answer

1. **Direct dependency on minih is viable and is the right move.** minih exposes a clean programmatic entry — `runAgent(adapter, definition, config)` from the `.`/`./runner` exports — and its backend is fully abstracted behind an `IAgentAdapter` interface (`run/compact/terminate`). `@github/copilot-sdk` is an *optional* peer dependency wired in only at the CLI composition root, so pij can implement claude-code/codex adapters and reuse minih's prompt assembly, input/output validation, permissions, and run recording without re-inventing any of it (F-01, F-02).
2. **Full input/output/validation compatibility comes for free** if pij consumes the folder contract as-is: all runtime config lives in `prompt.md` YAML frontmatter (`model`, `reasoning`, `timeout`, `coordination`, `permissions`); `agent.json` is a manifest the loader ignores; input arrives as `params` validated fail-fast by AJV against `input-schema.json`; output is a JSON envelope at `output/report.json` that must satisfy the system contract (`summary` + `retrospective`) plus the agent's own `output-schema.json`, with sibling `output/` files recorded as artifacts (F-05, F-06, F-07).
3. **The two features pij wants that minih does not have are ephemeral runs and inline agents.** Every run unconditionally writes a `runs/<ts>/` ledger under the agent dir (no suppress flag; retro auto-harvest *is* suppressible via `MINIH_NO_AUTO_HARVEST=1`), and `AgentDefinition` requires an on-disk folder — there is no run-from-a-prompt-string API. pij's inline/no-record mode therefore means synthesizing a temp agent folder and cleaning it up, or upstreaming both features to minih (F-03, F-04, R-03).
4. **pij already has every rail the feature needs.** A new `agent` verb slots into the existing `argv[2]` intercept block in the bin; harness/model/effort selection is already abstracted in pure builders (`parseSpawnArgs`, `buildControlSpawnCommand`) with the exact "unset ⇒ default" override semantics the user wants; `pij models` supplies the model+effort registry a non-copilot adapter needs (minih's own model validation is copilot-derived and best-effort); and the package-vetter path already invokes `minih run` and reads `output/report.json` — a liftable primitive (F-11, F-12, F-13, F-14, F-08).
5. **Agent defaults + instantiation-time override map cleanly onto existing contracts**: the pack's `prompt.md` frontmatter carries the pre-selected model/effort (harness inferable from the model's provider via `PROVIDER_HARNESS_MAP`); minih's own precedence is CLI > frontmatter > env > default, and pij spawn's precedence is flag > unset-means-harness-default — the same shape at both layers (F-05, F-08, F-13, F-14).
6. **A built-in flowspace-search agent is nearly trivial**: minimal viable agent is `prompt.md` alone; the fs2 CLI surface (`search/tree/get-node`, JSON envelope, `.fs2/graph.pickle` precondition) is what gets injected as instructions; the main constraint is minih's `restricted` default permission posture — the agent needs `shell: allow` to drive fs2 (F-16, F-17, F-09).
7. **One stance decision governs everything**: pij's own docs already declare pij's role is to *observe/coordinate* minih, "not replace Minih as the runner or artifact source of truth" (H-03). The library-vs-binary and subprocess-vs-tmux-session choices (R-04, R-05) are the load-bearing open decisions — hence the workshops below.

## Planning Handoff

- **Preserve**:
  - The minih folder contract exactly (prompt.md frontmatter as the single runtime config surface; `output/report.json` envelope with mandatory `summary`+`retrospective`; AJV input validation; runs ledger shape) — this *is* the compatibility requirement.
  - pij's pure builders (`parseSpawnArgs`, `buildControlSpawnCommand`) and models registry as the only harness/model/effort selection path (H-01, H-02).
  - minih as runner and artifact source of truth (H-03); pij wraps, lists, and orchestrates.
- **Change carefully**:
  - `cli.ts` `main()` intercept block + `USAGE` string (every new verb must appear in both).
  - `core/spawn.ts` copilot effort branch — resolve the `--effort` vs `--reasoning-effort` contradiction before agents depend on it.
  - `harness/scripts/vetters/agent.ts` — lift, don't duplicate, its minih-run/report-diff primitive.
- **Likely files/symbols**: `.pi/extensions/pij/cli.ts:869-894` (verb intercept), new `core/agents/` module (discovery: `./agents` + `~/.pij/agents` merge; run wrapper; ephemeral temp-pack synthesis), `core/models/registry.ts` (validation reuse), `core/spawn.ts` (only if tmux-session execution is chosen), `agents/` (built-in packs: flowspace-search first), minih dep via `github:AI-Substrate/minih#v<tag>`.
