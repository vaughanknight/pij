# Domain Registry

Lightweight registry for pij planning domains. This registry is intentionally small; it records boundaries that future plans can reuse without turning pij into a heavy domain-management project.

| Domain | Status | Primary Doc | Purpose |
|--------|--------|-------------|---------|
| `session-work-state` | active | [`session-work-state/domain.md`](./session-work-state/domain.md) | Session-scoped structured state for agent work, including persistence, reset, fork/new independence, and default work schema. |
| `agent-tooling-interface` | active | [`agent-tooling-interface/domain.md`](./agent-tooling-interface/domain.md) | Model-facing and operator-facing tool/command UX for pi extensions. |
| `extension-authoring-harness` | existing capability | [`../project-rules/harness.md`](../project-rules/harness.md) | Generator, tests, smoke, self-check, difficulty ledger, velocity log, and magic-wand feedback loop used by extension plans. |
| `agentic-loops` | active | [`agentic-loops/domain.md`](./agentic-loops/domain.md) | Long-running plan-driven autonomous loops over pi `createAgentSession()`. Owns `StopReason` taxonomy, `IterationRunner` lifecycle contract, markdown `PlanModel`, attribution/governance for community patterns (Ralph Loop), and "fresh context per iteration" discipline. First inhabitant: `.pi/extensions/ralph-loop/`. |
| `agent-workbench` | active | [`agent-workbench/domain.md`](./agent-workbench/domain.md) | Product contract for Pi-native Minih run visibility: read-only run summaries, view snapshots, adapter diagnostics, session pointer/cursor facade, and future gated interaction/push semantics without taking ownership of Minih artifacts. |
| `pij-messaging` | active | [`pij-messaging/domain.md`](./pij-messaging/domain.md) | Peer discovery + messaging + remote commands + event/state/liveness/receipt contracts, immutable inbox/read-marker semantics, push/pull ownership, ambient pull registration, and the additive `SessionDescriptor.prime` marker. |
| `file-watch-notify` | active | [`file-watch-notify/domain.md`](./file-watch-notify/domain.md) | Standalone extension that watches configured folders/globs and injects an in-session notice on file change (steered if busy, immediate if idle) with no tool call. Snapshot-reconcile classification (directory-watch-trap fix). Adapts pij's inject seam; no coupling to `pij-messaging`. |
| `flow-pair` | active | [`flow-pair/domain.md`](./flow-pair/domain.md) | Two-session orchestrator/worker delegation seam wrapping `the-flow` + a central cross-repo experiment/prompt-learning ledger. Owns packet/report schemas, run/delegation/review/learning records, prompt-cluster taxonomy (isolated), review rubric, and the `flow-pair` CLI surface. Consumes `pij-messaging` (worker delivery), `agent-tooling-interface` (skill/CLI surface), `extension-authoring-harness` (validation); `the-flow` + `minih` are external. |
| `pij-control-plane` | active | [`pij-control-plane/domain.md`](./pij-control-plane/domain.md) | Machine-wide control plane: single-instance daemon + TUI; tmux push delivery with retained envelopes/post-outcome markers; explicit pi/pull non-ownership; transport selection, readiness, deterministic binding, durable identity, and transcript tailing. |
| `agent-runtime` | active | [`agent-runtime/domain.md`](./agent-runtime/domain.md) | Runs minih-compatible agent packs from pij: 3-tier pack discovery (project→user→built-in) + precedence/shadowing; minih `runAgent` embedding with pij-authored `IAgentAdapter`s (claude/codex/copilot); instantiation-time model/effort/harness overrides + AJV fail-fast; ephemeral/inline temp-pack engine + crash-sweep; the `~/.pij/agents`+`~/.pij/tmp` path contract. Consumes `minih` (external library, exact tag) + `extension-authoring-harness`; excludes run UI (→`agent-workbench`), the pack format/validators/ledger (→minih), and CLI parsing (→`pij-control-plane`). |
| `pij-orchestration` | active | [`pij-orchestration/domain.md`](./pij-orchestration/domain.md) | Machine-wide primitives: atomic registry-backed batons and durable honor-system prime designation with exact-self set/unset targeting. |
| `pij-skill` | active | [`pij-skill/domain.md`](./pij-skill/domain.md) | The `/pij` router skill (`skills/pij/`): route registry + deterministic delivery-mode detection + shared conventions, including push-first tmux/pi guidance and `pij inbox --wait` for non-tmux peers. |
